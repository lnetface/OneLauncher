# 模组管理加载器图标

## 需求

模组管理 Pane（`GameDataModsManagerPane`）中，每个模组名称前显示一个小图标，表示该模组所属的加载器。

## 实现

修改 `OneLauncher/Views/Panes/GameDataModsManagerPane.axaml`：模组名称 `TextBlock` 外包一层 `Grid ColumnDefinitions="Auto,*"`，第一列放置 16×16 的 `controls:ThemeIcon`，第二列为原名称（保留 `CharacterEllipsis` 截断）。

- `IconKey` 绑定 `Info.mod`，通过全局 `UiOptionConverter`（`ConverterParameter=Icon`）映射为 `avares://OneLauncher/Assets/Imgs/<loader>` 图片，与新建实例 Pane 的加载器下拉框使用同一份映射，不新增图标资源或重复路径。
- `ToolTip.Tip` 绑定同一转换器的名称输出（Fabric / Forge / NeoForge / Quilt）。
- `IsVisible="{Binding !Info.IsUnknown}"`：无法识别的模组 `mod` 为 `none`，若显示会误导为“原版”，因此隐藏。图标间距使用 `Margin` 而非 `ColumnSpacing`，隐藏时名称不会留下空白缩进。
- ViewModel 无改动；绑定全部为编译绑定，`ThemeIcon` 内部缓存位图，兼容 AOT。

## 附带修复

`OneLauncher.Core/DefaultComponent/Resource/Mod/Manager/ModInfoGetter.cs` 中，检测到 `META-INF/mods.toml` 的 Forge 模组被错误标记为 `ModEnum.fabric`，现更正为 `ModEnum.forge`。否则 Forge 模组会显示 Fabric 图标。

## 已知限制与扩展

- 当前只通过 `fabric.mod.json` 识别 Fabric 系模组，`ModInfoGetter` 不读取 `quilt.mod.json`，因此仅含 Quilt 元数据的模组仍为未知模组；同时含两者的模组显示为 Fabric。若后端增加 Quilt 识别并设置 `ModEnum.quilt`，界面无需修改即可显示 Quilt 图标。
- 新增加载器时，只需在 `ModEnum` 和 `UiOptionConverter.Describe` 中补充映射。
