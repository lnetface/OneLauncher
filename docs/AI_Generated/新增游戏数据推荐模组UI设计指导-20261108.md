## 1. 新增文件：账户选项包装类

文件：`OneLauncher/ViewModels/Panes/GameDataAccountOption.cs`

命名空间：`OneLauncher.Views.Panes.PaneViewModels`（与现有 Pane ViewModel 一致）。

```csharp
public sealed class GameDataAccountOption
{
    public required string DisplayName { get; init; }
    public Guid? UserId { get; init; }
    public UserModel? User { get; init; }

    public bool IsGlobalDefault => UserId is null;

    public static List<GameDataAccountOption> Build(IEnumerable<UserModel> users)
    {
        var list = new List<GameDataAccountOption>
        {
            new() { DisplayName = "使用全局默认账户", UserId = null, User = null }
        };
        list.AddRange(users.Select(u => new GameDataAccountOption
        {
            DisplayName = u.Name,
            UserId = u.UserID,
            User = u
        }));
        return list;
    }
}
```

第一项永远是“使用全局默认账户”，它的 `UserId` 为 `null`。两个面板都用这个类，保证显示和保存逻辑一致。

### 2.3 推荐模组复选框

```csharp
[ObservableProperty] private bool installRecommendedMods;

public bool CanInstallRecommendedMods =>
    SelectedModLoader is not null && SelectedModLoader 不是“无加载器”;

partial void OnSelectedModLoaderChanged(<加载器类型> value)
{
    OnPropertyChanged(nameof(CanInstallRecommendedMods));
    if (!CanInstallRecommendedMods)
        InstallRecommendedMods = false;
}
```

“无加载器”的判断请按 `SelectedModLoader` 的实际类型写（枚举值或选项对象），不要用字符串比较。

### 2.4 保存后启动后台安装

`Save()` 成功写入游戏数据后，如果 `InstallRecommendedMods` 为 `true`，启动后台任务，不阻塞面板关闭：

```csharp
var task = taskManager.CreateTask($"安装推荐模组 {gameData.Name}");
var limited = new ModLimited(
    new ModType { /* 只把当前加载器对应的标志设为 true */ },
    gameData.VersionId,
    Than.GreaterThan);

var progress = new Progress<(int current, string file)>(p =>
    Dispatcher.UIThread.Post(() => { /* 更新 task 的进度文本 */ }));

_ = Task.Run(async () =>
{
    try
    {
        await resourceInstaller.InstallRecommendedMods(
            progress, gameData, limited, task.Token!.Token);
        // 标记任务完成，弹出成功提示
    }
    catch (OperationCanceledException)
    {
        task.Cancel();
    }
    catch (OlanException ex)
    {
        task.SetFailed(...);
        await OlanExceptionWorker.ForOlanException(ex);
    }
    catch (Exception ex)
    {
        task.SetFailed(...);
        await OlanExceptionWorker.ForUnknowException(ex);
    }
});
```

任务创建、进度回调、完成标记、失败处理的具体写法和 using，直接照搬 `InstallModPaneViewModel`，保持项目内一致。

提示消息使用 `MainWindowShowFlyoutMessage`：

- 开始：“已开始在后台安装推荐模组，可在任务列表查看进度”
- 成功：“推荐模组安装完成”
- 失败：“推荐模组安装失败，游戏数据已保留”

安装失败或取消时，不删除刚创建的游戏数据。

## 4. `EditGameDataPaneViewModel`

- 第 57 到 63 行：当前对 `GetUser(Guid?)` 的调用会出错，并且会把回退用户写回游戏数据。改为：用 `AvailableAccounts = GameDataAccountOption.Build(...)` 构建列表，按 `DefaultUserModelID` 查找对应项，ID 为 `null` 或找不到对应用户时选中全局默认项。删除写回逻辑，打开面板不能改动数据。
- 第 86 到 90 行：`OnSelectedAccountChanged` 改为写入 `DefaultUserModelID = value?.UserId`，然后保留原有的保存调用。初始化赋值期间如果会触发保存，用一个 `_isInitializing` 标志跳过。
- 第 156 行：还有一处使用 `DefaultUserModelID`，请确认它能处理 `null`，含义是“使用全局默认账户”。
