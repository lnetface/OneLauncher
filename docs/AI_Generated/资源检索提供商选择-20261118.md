# 资源检索页提供商选择-20261118

## 1. 目的

接入 `CurseForge资源获取与Modrinth现代化-20261119.md` 第 7 节留下的前端工作：在资源检索页选择资源提供商（Modrinth / CurseForge），并让安装侧栏把来源传给 `ResourceInstallerService`。

## 2. UI

工具栏顺序：搜索框 → **提供商下拉框** → 资源类型下拉框 → 搜索 → 清除。

- 提供商下拉框有三项：CurseForge + Modrinth、仅 CurseForge、仅 Modrinth。每项按提供商逐个显示“图标 + 名称”，“两者”项同时显示两个提供商。
- 提供商的每个条目与资源类型下拉框共用页面内的 `ResourceOptionTemplate`：`ThemeIcon`（20px）+ 名称，说明文字只放在 ToolTip 中。

### 图标（SKGT.resx 矢量，随前景色绘制）

| SKGT 键 | 图形 | 用于 |
| --- | --- | --- |
| `ProviderModrinth` | Modrinth 官方标志：断开圆环 + 扳手（Simple Icons，CC0） | `ResourceSource.Modrinth` |
| `ProviderCurseForge` | CurseForge 官方标志：铁砧（Simple Icons，CC0） | `ResourceSource.CurseForge` |
| `ResourceMod` | 拼图块 | `ResourceType.Mod` |
| `ResourceShaderPack` | 太阳 | `ResourceType.ShaderPack` |
| `ResourceModpack` | 叠层 | `ResourceType.Modpack` |

接入方式沿用 SKGT 约定：

1. 在 resx 中添加路径。
2. 在 `Converters/VectorIcons.cs` 中添加同名 `Geometry` 属性。
3. 在 `Controls/ThemeIcon.GetVector` 中把同名键映射到矢量。
4. 在 `UiOptionConverter` 中返回该键。

没有新增转换器或控件。

## 4. 逻辑

- `ResourceSourceOptions` 是 `ResourceSource[][]`，每个选项就是一组提供商，不另设选项类型。`SelectedResourceSources` 变化时清空列表并重新搜索。
- 默认选项：已配置 `Init.CurseforgeApiKey` 时选“CurseForge + Modrinth”，否则选“仅 Modrinth”，避免首次进入页面就报错。
- 搜索时，各已选提供商并行请求，结果按名次交替合并（`Interleave`），避免某个平台的结果全部排在后面。
  - 部分提供商失败：仍显示成功提供商的结果，状态栏提示哪个提供商失败，失败原因交给 `OlanExceptionWorker`。
  - 全部失败：沿用原来的“搜索失败，请重试。”
  - 提供商为空（理论上不会出现）：提示“请至少选择一个资源提供商。”
- 原有的 generation 与取消机制保证旧请求的结果不会覆盖新请求的结果。
- 每个 `ResourceItem` 带有 `Source`，安装侧栏按该来源调用 `ResourceInstallerService`，所以合并后的列表可以混装两个平台的资源。
- CurseForge 结果映射：
  - `Id` 转为字符串作为 `ID`。
  - 图标优先使用 `Logo.ThumbnailUrl`。
  - 支持的版本来自 `GetSupportedGameVersions()`；模组同 Modrinth 一样经过 `McVsFilter`。
  - 加载器来自 `GetSupportedModLoaders()`。

## 5. 扩展

新增平台时，按以下步骤接入：

1. 在 `ResourceSource` 中添加枚举值，并在 `ResourceSourceOptions` 中加入需要的组合。
2. 在 SKGT.resx 中绘制该平台的图标，并在 `UiOptionConverter` 中补充图标和名称。
3. 在 `SearchAsync` 的 switch 中调用新平台的搜索接口，并补充对应的 `ResourceItem.Create` 重载。

安装侧栏只需传递 `Source`，不需要修改。
