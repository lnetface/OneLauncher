# UI 图标与说明增强行动文档（2026-10-30）

> 本文档按“说明执行”要求编写，只描述后续实施计划，本轮不修改项目代码。

## 1. 目标

设置页“主页默认启动项”采用了“图标 + 名称 + 次要说明”的下拉项，用户反馈很好。本次计划把这套表达方式推广到其他高频选择控件，同时完成两项明确需求：

1. 设置页“主页背景”不再显示文件名。
2. 主页背景固定保存为 `%BasePath%/customdata/home-background.png`。全局只保留这一个文件，不再使用 uuid/guid 子目录。

另外补充 Java、图片、内存、下载源和账户类型等图标；模组加载器沿用项目已有图片。下载游戏实例面板中的安装选项不增加图标。

> 实施修订：通用图标采用 Icons8 Apple SF Regular PNG，放入 `Assets/icos` 并由生成脚本创建 Light/Dark 资源。Java 和 Microsoft 两个缺失图标在 `SKGT.resx` 中矢量绘制。

## 2. 现状分析

### 2.1 主页背景

- `OneLauncher/Codes/HomeBackgroundStore.cs` 目前保存到 `customdata/home-background/<guid>/<原文件名>`，读取时返回最新的图片。
- `SettingsPageViewModel` 提供 `HomeBackgroundDisplayName`，`settings.axaml` 在“选择背景图片/移除背景”后面显示文件名，例如截图中的 `original.jpg`。
- `HomePageViewModel.LoadHomeBackground` 用“路径是否变化”判断是否重新加载。改成固定路径后，路径会一直相同，现有判断会让更换后的背景无法刷新。

### 2.2 图标资源

- 位图图标位于 `OneLauncher/Assets/icos`，通过 `Theme.axaml` 的 Light/Dark 资源提供。目前没有 Java、模组加载器、图片和内存相关图标。
- 矢量图标保存在 `OneLauncher/Assets/Resources/SKGT.resx`，由 `OneLauncher/Converters/VectorIcons.cs` 缓存为 `Geometry`。现有 SKGT 是适合 `PathIcon` 的填充路径。
- 不在 AXAML 或 ViewModel 中复制原始路径，统一新增 SKGT 键和 `VectorIcons` 属性。

### 2.3 可改进位置

| 位置 | 当前状态 | 改进方向 |
| --- | --- | --- |
| `DownloadPane.axaml` 安装选项 | 纯文字 CheckBox | 按用户要求保持不变 |
| `settings.axaml` 主页背景 | 文字按钮 + 文件名 | 删除文件名，按钮改为图标 + 文字 |
| `settings.axaml` 主页样式 | 字符串下拉项 | 图标 + 名称 + 说明 |

## 3. 图标来源与授权策略

1. 通用界面图标使用 README 中注明的 Icons8，并统一选择 Apple SF Regular 风格。
2. Java 和 Microsoft 没有采用位图，分别以 24x24 矢量路径保存到 `SKGT.resx`。
3. Fabric、Quilt、NeoForge、Forge 和原版使用 `Assets/Imgs` 中已有图片。

## 4. 实施步骤

### 4.1 主页背景固定文件

修改 `HomeBackgroundStore`：

- 当前文件固定为 `Path.Combine(CustomDataPath, "home-background.png")`。
- 导入时先把源图片解码为 Avalonia `Bitmap`，校验尺寸，再保存为真实 PNG 到同目录临时文件，例如 `home-background.png.tmp`。
- 临时文件重新解码校验成功后，用 `File.Move(temp, target, overwrite: true)` 替换正式文件。失败时删除临时文件，并继续抛出 `OlanException`，由现有调用链交给 `OlanExceptionWorker` 处理。
- `Clear` 只删除 `home-background.png`。
- 兼容旧数据：首次读取时，如果固定文件不存在而旧目录 `customdata/home-background/` 中有图片，就把最新一张有效图片重新编码迁移到固定文件，然后尽力删除旧目录。迁移失败不影响启动，只视为未设置背景。
- 新增一个只增不减的背景版本号，或在 `Changed` 中携带刷新原因，让主页即使路径不变也知道需要重新加载。

修改 `HomePageViewModel`：

- `LoadHomeBackground` 不再只比较路径，还要结合背景版本号或文件最后写入时间判断是否重新加载。
- 通过 `FileStream` 打开图片并完整解码，然后立即关闭文件，避免主页持有文件句柄导致下一次替换失败。
- 保留现有超宽图片缩放和加载失败通知逻辑。

修改设置页：

- 删除 `HomeBackgroundDisplayName` 和对应的 `NotifyPropertyChangedFor`。
- 删除 `settings.axaml` 中显示文件名的 `TextBlock` 和路径 ToolTip。
- “选择背景图片”和“移除背景”改为图标 + 文字按钮，分别使用 `Image` 和 `ImageRemove` 矢量。

### 4.2 新增图标

Icons8 PNG 包括图片添加/移除、内存、盾牌、速度、闪电、魔法、仪表盘、云、云下载、钥匙和用户。`SKGT.resx` 只新增 `JavaLogo` 与 `MicrosoftLogo`。

### 4.3 下载面板复选框

按用户修订，下载游戏实例部分的安装选项不增加图标，`DownloadPane.axaml` 不修改。

### 4.4 推广“图标 + 名称 + 说明”下拉项

1. 主页经典样式快速启动：复用设置页默认启动项的布局，显示 `IQuicklyLaunchItem.Icon`、`Name` 和 `Description`，选中框也显示图标和名称。
2. 主页样式：把 `string` 列表替换为轻量展示项 `HomePageStyleOption(Value, DisplayName, Description, Geometry Icon)`。配置仍保存原有值，避免配置格式变化。
3. 下载源：把 `DownloadSourceStrategy` 转换为 `DownloadSourceOption(Strategy, DisplayName, Description, Geometry Icon)`，或者新增 AOT 友好的显式转换器提供说明文字。写回配置时仍使用原枚举值。
4. Java 安装：版本项显示 Java 图标、版本号和 LTS/普通版本说明；提供商项沿用 `JavaProviderItem`，补充最低支持版本和用途说明。
5. 新建实例：加载器下拉项根据 `ModEnum` 显示对应矢量图标；用户下拉项显示账户图标或已有头像，并以账户类型作为次要说明。
6. 登录类型：静态 `ComboBoxItem` 改为带图标和说明的内容。现有 `SelectedItem` 判断依赖 `ComboBoxItem.Content` 时，需要同步改成稳定的类型值或 `SelectedIndex`，避免模板化后登录逻辑判断失效。

所有展示项使用强类型 `record` 或 `sealed class` 和编译绑定，不使用反射或动态绑定，满足 AOT 要求。

### 4.5 设置页按钮与开关

- “安装 Java”使用 `Java` 图标。
- “释放内存（预览版）”使用 `Memory` 图标。
- “控制左侧导航栏页面”可复用现有导航位图图标，在导航项 CheckBox 前显示对应页面图标。
- JVM 优化 RadioButton 增加次要说明，例如兼容优先、平衡、性能优先。是否加图标以视觉噪声为准，优先保持清晰。
