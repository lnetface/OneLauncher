# Quilt 实例依赖缺失启动失败修复

## 问题

实例 `968bf361` 使用 Minecraft 1.21.11 和 Quilt。启动命令中的 Quilt Loader、hashed、Mixin 等库文件不存在，Java 无法加载 `KnotClient`。

## 原因

1. `DownloadMinecraft.MinecraftBasic` 的加载器任务条件写反，存在加载器时跳过了加载器依赖下载。
2. Quilt Meta 已为每个通用库提供 `url`，旧代码统一使用 Quilt Maven，导致 Fabric Maven 上的库地址错误。
3. Quilt Meta 返回顺序不是版本顺序，旧代码选择首项，得到 `0.20.0-beta.9`。

## 修改

- 修正加载器依赖下载条件。
- `FabricLibrary` 保存可选的 `url`，Quilt 解析器优先使用元数据中的仓库地址；旧文件缺少地址时，`org.quiltmc` 使用 Quilt Maven，其余使用 Fabric Maven。
- Quilt Provider 优先选择最高稳定版，没有稳定版时回退到接口首项。
- ConsoleTest 支持 `quilt:<版本>`，Quilt 测试默认不下载 QSL，以聚焦加载器启动链。

## 验证

`--cases quilt:1.21.11 --seconds 60` 完成安装并启动，日志显示 Quilt Loader 0.30.1 加载 Minecraft 1.21.11，并出现 LWJGL 渲染初始化标记。
