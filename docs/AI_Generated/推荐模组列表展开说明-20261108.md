# 推荐模组列表展开说明

`OneLauncher.Core/Global/ModelDataMangers/DBManager.cs` 的 `DefaultConfig.RecommandedMods` 已改为直接创建 `RecommendedMod`、`ModLimited` 和 `ModType`，并移除私有 `Mod` 辅助方法。

列表使用 `#region 推荐模组` / `#endregion` 分组，便于在编辑器中折叠和维护。现有十项模组的顺序、加载器标志、最低版本和 `Than.GreaterThan` 条件均保持原值。

后续新增推荐模组时，直接在列表中添加对象，填写 Modrinth slug、加载器标志、版本与比较条件。此变更只调整默认值的代码表达方式，无需迁移已有配置文件。
