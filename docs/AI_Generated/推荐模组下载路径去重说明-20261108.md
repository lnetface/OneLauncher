# 推荐模组下载路径去重说明

`RecommendedModInstaller.InstallAsync` 在收集所有主模组和依赖后、调用批量下载前，按 `Path.GetFullPath(item.path)` 去重，保留相同目标路径第一次出现的下载项及其顺序。

多个推荐模组可能共同依赖同一模组，依赖也可能已经列入推荐清单。原先这些下载项会分别进入并发下载，竞争写入同一目标文件及临时文件。按最终保存路径统一去重可以覆盖这两种来源，以及重复的推荐项；相同文件名但位于不同目录的目标仍分别保留。

路径归一化可以识别 `.`、`..` 等等价写法。Windows 使用 `StringComparer.OrdinalIgnoreCase`，其他系统使用 `StringComparer.Ordinal`，避免在区分大小写的系统上错误合并两个文件。不同 URL 指向同一个保存路径时同样只保留第一项。

修改文件：`OneLauncher.Core/DefaultComponent/Resource/ResourceGetterService/AutoInformation/RecommededMods/RecommendedModInstaller.cs`。`ConsoleTest/RecommendedModsChecks.cs` 扩展离线回归场景，由既有 `--recommended-mods` 入口执行。不增加反射或跨平台锁到生产代码。

核心项目和 `ConsoleTest` 编译通过，Windows 下 21 项离线检查通过。新增场景使用 4 个下载并发，覆盖两个主模组的共同依赖、依赖同时作为推荐项、重复推荐项、`./` 等价路径及大小写不同但相同的 Windows 路径。断言每个目标仅下载一次，文件内容正确，并保留先前无兼容版本与空依赖的回归检查。测试没有访问真实 Modrinth；夹具和隔离构建目录已清理，`git diff --check` 通过。

此去重只作用于单次推荐模组安装的下载列表。不同安装任务同时写入同一实例的文件，仍需任务协调或下载器中的文件写入协调机制；该行为不在本次修改范围内。
