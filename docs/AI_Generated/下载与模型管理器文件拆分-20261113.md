# 下载类与模型管理器文件拆分

本次仅整理文件职责，保留当前工作区中的方法实现、类型名称、命名空间、访问级别及 JSON 格式。

## 下载类

- `OneLauncher.Core/DefaultComponent/Downloader/Download.cs`：构造函数、共享 HttpClient 字段和 Dispose。
- `DownloadTool.cs`：批量下载、HTTP 流获取、普通文件下载、临时文件辅助方法与文件存在性检查。
- `DownloadExtra.cs`：ZIP 解压、大文件分段下载、带 SHA-1 校验的下载与 SHA-1 检查。

三个文件共同构成原有 Download partial 类，调用方无需修改。通用下载能力继续添加到 DownloadTool.cs，校验和扩展能力添加到 DownloadExtra.cs。

## 模型管理器

AccountManger.cs、DBManager.cs、GameDataManger.cs、VersionListManager.cs 保留各自的管理器实现。新增 AccountManager.JsonModels.cs、DBManager.JsonModels.cs、GameDataManager.JsonModels.cs、VersionListManager.JsonModels.cs，分别存放对应数据模型、枚举及 JsonSerializerContext。

BasicDataManger.cs 本身仅包含通用管理器，无独立数据模型，保持原样。原有文件名和 ModelDataMangers 命名空间保持不变。

JSON 源生成声明和反序列化回调随模型原文搬移，保留 AOT 支持。未来添加模型字段或序列化类型时，修改对应 JsonModels 文件；管理行为修改原管理器文件。

## 检查

拆分时按原文本片段搬移，并核对 Download 的所有成员片段完整覆盖原类体。进行了静态差异与文件职责检查；按项目对非大型功能改动的约定，未运行构建或测试。
