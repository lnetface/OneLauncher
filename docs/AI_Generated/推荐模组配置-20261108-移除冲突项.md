来源：Modrinth 官方项目与版本 API。保留原始整合包的 49 个模组，添加 Sound Physics Remastered、Dynamic Surroundings（Fabric 项目）、IMBlocker 原版，以及示例中的 QSL、Embeddium、JEI、ModernFix 原项目。原列表共 56 个不同项目；本修订移除 BetterGrassify、Cape Provider、Cubes Without Borders，剩余 53 个不同项目；资源包不纳入模组列表。

ModId 使用稳定的 Modrinth 项目 ID；注释给出 slug。按加载器分别核对最低已发布数字版本，相同最低版本的加载器合并。GreaterThan 在当前项目实现中表示大于等于。此配置只表达最低版本，不保证之后每个版本均有文件；必须再通过 API 按实际游戏版本和加载器精确筛选，并跳过无匹配文件的项目。快照和预发布版本未纳入边界。

同一项目可能有多个条目，这是不同加载器的支持边界，不应重复安装。两个边界条目不能当作上下限使用，因为当前列表会逐条处理，无法表达 AND 区间。
