# 共享依赖并发下载临时文件修复

## 问题

26.2 的 Fabric 和 Quilt 元数据都包含 `org.ow2.asm:asm-util:9.10.1`。加载器依赖合并后未去重，批量下载会并行打开同一个 `asm-util-9.10.1.jar.downloading`，触发文件占用异常。固定临时文件名也会导致独立安装任务互相覆盖、清理临时文件。

## 修改

- `DownloadMinecraftPlanner.cs`：按完整目标路径去重合并后的加载器依赖和总校验清单，减少重复下载条目及重复进度计数。
- `Download.cs`：批量下载入口按完整目标路径去重，覆盖其他调用者；临时路径加入每次请求独立的 GUID，下载和 SHA-1 校验下载都沿用原有完成后移动、失败后清理的流程。
- `RaceDownloader.cs`：复用同一临时路径生成方法，避免与普通下载或其他竞速下载共享临时文件。

Windows 使用不区分大小写的路径比较，其他系统使用区分大小写的比较。现有源选择与下载重试行为保持不变；同一批次相同目标路径保留首个条目。实现不引入反射，兼容 AOT。

## 范围与后续扩展

此次处理重复目标和临时文件冲突；独立任务仍可各自下载同一最终目标文件。未来如需跨任务避免重复流量，可增加按目标路径合并请求的调度机制。

按项目要求，本次小范围修复仅做静态检查和差异检查，未运行并发下载测试、游戏安装或 AOT 构建。
