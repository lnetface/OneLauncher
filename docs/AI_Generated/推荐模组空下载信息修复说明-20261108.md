# 推荐模组空下载信息修复说明

日期：2026-11-08

用户授权替换 `RecommendedModInstaller.InstallAsync` 的查询对象创建和下载信息收集代码，修复 `Nullable object must have a value` 异常。

原先的惰性 `Select` 在初始化和收集下载信息时分别创建不同的 `GetModrinth` 对象，后者未初始化。项目不存在或无兼容版本时，已有初始化流程也会留下空下载信息。直接取 `.Value` 因而抛异常。

现在创建查询对象后立即 `.ToList()`，所有后续步骤复用同一批对象。收集主文件前检查 `HasValue`，无文件时跳过该项目；只有主文件可用时才收集依赖，空依赖列表按空集合处理。

查询 Minecraft 版本改为实例的 `gameData.VersionId`，下载目录改为 `Path.Combine(gameData.InstancePath, "mods")`，不再使用清单最低版本查询或写入相对目录。

修改文件：`OneLauncher.Core/DefaultComponent/Resource/ResourceGetterService/AutoInformation/RecommededMods/RecommendedModInstaller.cs`。回归检查由 `ConsoleTest/RecommendedModsChecks.cs` 与 `ConsoleTest/Program.cs` 的 `--recommended-mods` 入口提供，模拟正常项目、HTTP 404 和空版本列表，不联网、不读取实际启动器配置。夹具在工作区内生成并自动清理。

核心项目及 `ConsoleTest` 编译通过，12 项离线检查通过：每个项目仅请求一次元数据，查询使用实例实际版本，正常主文件写入实例绝对 `mods` 目录，404、空版本列表和空依赖均不触发本次异常。`git diff --check` 通过。夹具及隔离构建目录在检查后清理，未执行真实 Modrinth 下载或完整 AOT 发布。

此次保持原有模组筛选和网络错误处理规则。后续仍应按每项 `x.Limited` 筛选，并为快照及预发布版完善版本比较；无兼容版本与解析异常的区别应由 `GetModrinth` 提供给调用方。

后续已增加批量下载前的目标路径去重，说明见 [推荐模组下载路径去重说明-20261108.md](推荐模组下载路径去重说明-20261108.md)。
