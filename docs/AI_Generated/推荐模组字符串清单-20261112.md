# 推荐模组字符串清单

DefaultConfig.RecommandedMods 改为 List<string>，只保存 Modrinth 项目 ID 或 slug。原默认清单按首次出现顺序合并为 53 个唯一 ID，保留名称注释。新增推荐模组时只需添加字符串。

移除 RecommendedMod、ModLimited 模型及安装接口中的限制参数，前端直接传入游戏数据。安装器使用实例版本和加载器查询 Modrinth，沿用找不到模组或无兼容版本时跳过、下载路径去重的行为。

RecommendedModListConverter 兼容旧对象数组，读取时提取 ModId 并合并重复对象，保存时输出字符串数组。转换器直接使用 JSON reader/writer，与现有源生成上下文配合，不依赖反射，适配 AOT。

同步调整已有 ConsoleTest 夹具中的清单类型、接口调用和 JSON 断言。按项目要求，此次小范围修改未运行测试。
