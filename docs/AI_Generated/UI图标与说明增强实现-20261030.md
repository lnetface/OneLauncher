# UI 图标与说明增强实现（2026-10-30）

## 结果

1. 主页背景固定保存为 `%BasePath%/customdata/home-background.png`。导入时会先解码，再写成真实 PNG，并通过临时文件替换。旧的 `customdata/home-background/**` 会在读取时迁移。
2. 设置页不再显示背景文件名。“选择背景图片”和“移除背景”改为图标加文字的按钮。
3. 以下位置改为“图标 + 名称 + 说明”：设置分类、主页样式、下载源、JVM 模式、经典主页快速启动、Java 版本、新建实例加载器、默认用户和登录方式。
4. 下载游戏实例面板中的安装选项保持原样，不增加图标。

## 图标来源

通用图标使用 Icons8 Apple SF Regular PNG。图片放在 `OneLauncher/Assets/icos`，由 `scripts/Generate-ThemeIcons.ps1` 生成白色版本，并写入 `Theme.axaml`。

| 资源键 | Icons8 名称 | 用途 |
| --- | --- | --- |
| `IconImageAdd` | add-image | 选择主页背景 |
| `IconImageRemove` | remove-image | 移除主页背景 |
| `IconMemory` | memory-slot | 释放内存 |
| `IconShield` / `IconSpeed` / `IconLightning` | shield / speed / lightning-bolt | JVM 模式 |
| `IconMagic` / `IconDashboard` | fantasy / dashboard | 主页样式与主页板块 |
| `IconCloud` / `IconCloudDownload` | cloud / download-from-cloud | 下载源 |
| `IconUser` / `IconKey` | user / key | 离线和外置账户 |

Java 与 Microsoft 图标由项目矢量绘制，保存在 `SKGT.resx` 的 `JavaLogo` 和 `MicrosoftLogo`，并在 `VectorIcons.cs` 中缓存为 Geometry。Java 使用圆角描边以贴近 SF Regular；Microsoft 使用四格填充图形。两者都跟随当前前景色，所以 Light/Dark 主题不需要复制两份图形。

模组加载器使用 `Assets/Imgs` 中已有的 Fabric、Quilt、NeoForge、Forge 和原版图片。

## 实现说明

`ThemeIcon` 是统一的 AOT 友好图标控件，支持三类图标键：

- `Icon*`：读取 Theme 位图资源，并随主题切换。
- `JavaLogo` / `MicrosoftLogo`：绘制 SKGT 矢量。
- `avares://...`：读取固定彩色图片，供模组加载器使用。

`UiOptionConverter` 把原有设置值映射为图标、名称和说明。ComboBox 仍然保存原始字符串、枚举或数字，因此配置格式和现有回归测试入口不变。登录方式改为强类型 `AccountType`，不再比较 `ComboBoxItem.Content`。

## 扩展方式

新增通用图标时，下载同一 Icons8 Apple SF Regular 风格的 PNG，按字母数字命名后放入 `Assets/icos`，再运行生成脚本。只有缺少合适 Icons8 图标时才在 SKGT 中绘制，并同步在 `VectorIcons` 和 `ThemeIcon` 中注册。
