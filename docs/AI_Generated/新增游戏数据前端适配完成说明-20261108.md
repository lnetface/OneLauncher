# 新增游戏数据前端适配完成说明

日期：2026-11-08

前端依据 `新增游戏数据推荐模组UI设计指导-20261108.md` 完成。本文记录实际实现及验证结果，后端待修复项以本文核查为准。

## 实现行为

新增与编辑游戏数据的账户下拉框共用 `GameDataAccountOption`。首项为“使用全局默认账户”，对应 `UserId = null`；其余选项保留具体账户 ID。新增面板默认选中全局选项，即使尚无账户也能创建游戏数据。实际启动时的账户解析仍由后端负责。

编辑面板按已保存的账户 ID 选择选项，空 ID 或已删除账户显示全局选项。初始化期间阻止账户和标签回调保存，打开面板不会改写实例。用户切换账户会立即保存；点击保存也会写入当前选项，因此可以明确把失效账户改为全局默认。取消面板沿用既有行为，已立即保存的账户选择会保留。

新增面板的“实例信息”下增加“工具”板块，复用既有 Pane 样式。推荐模组默认不勾选，仅 Fabric、Quilt、Forge、NeoForge 可启用；切换到无加载器或清空基础版本时会取消勾选并禁用。

创建实例成功后，勾选推荐模组会登记任务中心任务，通过 `Task.Run` 调用 `ResourceInstallerService.InstallRecommendedMods`，并立即关闭面板。两个工厂重载均传入资源安装服务和任务管理器。创建保存失败时保持面板打开，并通过 `OlanExceptionWorker` 展示错误。

后台安装使用任务的取消令牌，进度回调派发到 UI 线程，终态后忽略迟到的进度。当前后端只提供文件序号和文件信息，没有文件总数，因此显示下载文件文本，接口成功返回后才标记 100%。返回后再次检查取消令牌，避免后端吞掉取消异常时误报成功。成功、失败、取消均提供通知，可点击进入任务列表；失败和取消保留实例及已下载的文件，不自动重试或删除实例。

## 后端仍需修复

用户后续授权替换 `RecommendedModInstaller.cs` 的下载对象与结果收集逻辑，已修复重复创建未初始化对象、空下载信息和空依赖列表，并改为查询实例实际版本及写入实例绝对路径。详见 [推荐模组空下载信息修复说明-20261108.md](推荐模组空下载信息修复说明-20261108.md)。

推荐安装器仍有以下待改进项：

1. 适配条件应读取每项的 `x.Limited`；当前读取统一传入的限制，按前端传当前版本和加载器会让全部推荐项通过。
2. `new Version(gameData.VersionId)` 无法处理快照、预发布版和自定义版本 ID。

`GameData.GetUserModel()` 对失效的显式账户 ID 仍抛异常。编辑面板显示全局选项但不自动改写失效 ID，用户需明确保存或切换账户才能写入 `null`；启动时自动回退需要后端实现。`GameLauncher` 也仍重复解析账户并忽略 `IntelligentLogin` 返回的用户，需要后端确认。

此前文档单凭缺少推荐模组类型的显式 `JsonSerializable` 注册推断 AOT 风险并不充分：JSON 源生成器会递归处理 `AppConfig` 引用的类型，完整发布验证仍需另行执行。
